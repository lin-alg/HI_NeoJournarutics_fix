# Intel 核显无法开启光影及关联崩溃问题解决方案

## 一、 问题概述
出问题的模组链接：
1. [veil-neoforge-1.21.1-4.1.4.jar](https://www.mcmod.cn/class/25225.html)
2. Alltheleaks 模组
3. create_flight_control 模组

## 二、 解决方法
1. 更新 Alltheleaks 模组至 1.1.10。
2. 由于 veil 模组包含在 sable 模组内，所以更换 sable 模组即可。若是独立模组，则替换 veil 模组（附件在此文件夹内）。
3. 替换 create_flight_control 模组。
4. alltheleaks 模组开启时，不能开启 photon 光影（或者在光影设置中关闭光照-球谐天空光即可兼容）。

## 三、 开发者指南
1. alltheleaks 模组对 supplementaries 模组的优化已经过时，alltheleaks新版本已修复。untrackedissues001 在新版本的 supplementaries 模组中已不适用。
2. create_flight_control 模组调用了 create-aeronautics-bundled-1.21.1-1.3.0 模组内子模组 `dev.simulated_team.simulated.simulated-neoforge-1.21.1-1.3.0.jar` 的一个方法 `getLaserRange()`，但是该方法已改名为 `getRaycastLength()`。
3. veil 模组内的 `/assets/veil/pinwheel/shaders/program/light/indirect_sphere.comp` 文件内：
   ```glsl
   layout(std430) readonly buffer VeilLightInstanced {
       float data[];
   };

   layout(std430) writeonly buffer VeilLightIndirect {
       int commands[];
   };
   ```
   这段代码的 `readonly` 和 `writeonly` 会出现报错：
   `[Render thread/INFO] [com.mojang.blaze3d.platform.GlDebug/]: OpenGL debug message: id=0, source=SHADER COMPILER, type=ERROR, severity=HIGH, message='SHADER_ID_COMPILE error has been generated. GLSL compile failed for shader 57, "compute Shader veil:light/indirect_sphere": ERROR: 0:24: 'readonly' : reserved word`
   
   去掉 `writeonly` 和 `readonly` 关键字则正常。大概率和 intel 核显有关。

*注：开启 alltheleak 的时候（不论新旧版本），如果同时开 photon 光影，则会出现 readonly 报错（而且不止该报错，修复 sable 只是解决了一个问题）。最后又发现，photon 在光影设置中关闭光照-球谐天空光即可兼容。因此 writeonly 和 readonly 关键字的问题和别的问题都只是开启光照-球谐天空光后出现的问题。*
